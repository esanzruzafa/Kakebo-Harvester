# Kakebo Harvester 2.0.2 — notas de actualización

Esta actualización de mantenimiento reúne Electron 44.7.0, read-excel-file 9.3.12, dotenv 18.0.7 y los tipos de SQLite 9.6.0. Actualiza también el linter, Next.js de las páginas legales y las acciones de preparación de Node.js.

## Antes de actualizar

1. Cierra Kakebo Harvester y cualquier tarea programada que lo utilice.
2. Conserva una copia privada de `data/`, `config/`, la configuración privada y los certificados de tu instalación.
3. Sustituye el ejecutable por el de 2.0.2 y abre la aplicación con tu instalación habitual.

La base de datos conserva el esquema 19. Si actualizas desde 1.0.2, consulta las [notas de 2.0.0](2.0.0.md).

La aplicación mantiene la importación local de solo lectura. Sigue pendiente el aviso moderado del empaquetador descrito en [#52](https://github.com/esanzruzafa/Kakebo-Harvester/issues/52).

## Descargas

La release incluirá el ejecutable portable, el paquete completo ZIP y sus sumas SHA-256. Conserva tus archivos privados al actualizar.
