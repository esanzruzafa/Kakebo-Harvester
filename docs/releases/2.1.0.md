# Kakebo Harvester 2.1.0 — notas de actualización

Esta versión permite añadir columnas personalizadas a los perfiles de exportación CSV y XLSX: columnas con fórmulas locales y columnas vacías para completar manualmente.

Las fórmulas se evalúan únicamente para los movimientos nuevos. En sincronizaciones posteriores se conservan los valores de las columnas personalizadas de los movimientos existentes, incluidas las ediciones manuales. Los movimientos nuevos reciben una celda vacía en las columnas sin fórmula.

La importación del archivo anterior valida sus cabeceras, las claves de movimiento y la precisión numérica. Si el archivo está dañado o su estructura ya no corresponde al perfil, la exportación se detiene y conserva el archivo original. Las fórmulas usan un evaluador local restringido; no ejecutan JavaScript ni fórmulas de Excel.

Las exportaciones interrumpidas entre la instalación del archivo y la persistencia de su estado se recuperan mediante un estado pendiente y la verificación del hash del archivo generado.

Incluye la corrección de dependencias integrada desde main. Esta actualización es compatible con los perfiles existentes y no cambia el esquema de la base de datos.

## Antes de actualizar

1. Cierra Kakebo Harvester y las tareas programadas que lo utilicen.
2. Conserva una copia privada de `data/`, `config/`, los archivos exportados y los certificados de tu instalación.
3. Sustituye el ejecutable por el de 2.1.0 y abre la aplicación con tu instalación habitual.

Si actualizas desde 1.0.2, consulta primero las [notas de 2.0.0](2.0.0.md).

## Descargas

La release incluye el ejecutable portable, el paquete completo ZIP y sus sumas SHA-256. Conserva tus archivos privados al actualizar.
