# Kakebo Harvester 2.1.0 — notas de actualización

Esta versión permite añadir columnas personalizadas a los perfiles de exportación CSV y XLSX: columnas con fórmulas locales y columnas vacías para completar manualmente.

Las fórmulas se evalúan únicamente para los movimientos nuevos. En sincronizaciones posteriores se conservan los valores de las columnas personalizadas de los movimientos existentes, incluidas las ediciones manuales. Los movimientos nuevos reciben una celda vacía en las columnas sin fórmula.

Conserva las claves `movementKey` de cada movimiento. Para ordenar el archivo, selecciona filas completas: modificar o intercambiar solo las claves cambia la asociación de las columnas personalizadas. La protección adicional frente a ese tipo de edición se sigue en [#67](https://github.com/esanzruzafa/Kakebo-Harvester/issues/67).

La importación del archivo anterior valida sus cabeceras, las claves de movimiento y la precisión numérica. Si el archivo está dañado o su estructura ya no corresponde al perfil, la exportación se detiene y conserva el archivo original. Las fórmulas usan un evaluador local restringido; no ejecutan JavaScript ni fórmulas de Excel.

Las exportaciones interrumpidas entre la instalación del archivo y la persistencia de su estado se recuperan mediante un estado pendiente. Se verifica el hash del archivo generado o, si se ha editado después de la interrupción, sus cabeceras y claves de movimiento para conservar las ediciones.

Incluye la corrección de dependencias integrada desde main. Esta actualización es compatible con los perfiles existentes y no cambia el esquema de la base de datos.

Queda en seguimiento [#66](https://github.com/esanzruzafa/Kakebo-Harvester/issues/66): algunas representaciones decimales largas y poco habituales de celdas XLSX se rechazan de forma conservadora. En ese caso el archivo original y su estado se conservan.

Si editaste directamente el JSON de configuración de una instalación 2.0 antes de su primera exportación 2.1 y no existe copia de la configuración anterior, el perfil puede considerarse distinto incluso al cambiar una opción inactiva. Se conserva el archivo anterior en `archive/`, pero se regeneran el resultado y el resaltado. Esta limitación de migración se sigue en [#68](https://github.com/esanzruzafa/Kakebo-Harvester/issues/68).

Si falla una exportación con cambio incompatible de perfil y también falla la restauración del archivo histórico, se conserva el original en `archive/`, pero puede ser necesaria una recuperación manual antes de exportar de nuevo. La recuperación automática de ese doble fallo se sigue en [#69](https://github.com/esanzruzafa/Kakebo-Harvester/issues/69). Conserva una copia privada de los archivos y del estado antes de intervenir.

## Antes de actualizar

1. Cierra Kakebo Harvester y las tareas programadas que lo utilicen.
2. Conserva una copia privada de `data/`, `config/`, los archivos exportados y los certificados de tu instalación.
3. Sustituye el ejecutable por el de 2.1.0 y abre la aplicación con tu instalación habitual.

Si actualizas desde 1.0.2, consulta primero las [notas de 2.0.0](2.0.0.md).

## Descargas

La release incluye el ejecutable portable, el paquete completo ZIP y sus sumas SHA-256. Conserva tus archivos privados al actualizar.

Resuelve [#3](https://github.com/esanzruzafa/Kakebo-Harvester/issues/3).
